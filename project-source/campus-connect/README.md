# Campus Connect

A beginner-friendly command-line campus directory built with Python. It can add, list, search and remove student contact records. Records are stored locally in `students.json`.

## Requirements
- Python 3.9 or newer

## Run
```bash
python main.py
```

Choose an option from the menu. The `students.json` file is created automatically when the first record is saved. This is a learning/demo project; use sample data only.
