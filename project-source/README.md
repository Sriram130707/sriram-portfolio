# Portfolio Project Source Code

This folder contains the source code and an individual README for each project displayed in the portfolio.

- `campus-connect/` — Python CLI campus directory
- `java-core-concepts/` — Java fundamentals example
- `java-with-oop/` — Java OOP example
- `html-basic-details/` — HTML student details form
- `css-landing-page/` — responsive CSS landing page

Each folder's README explains how to run its example. These are starter/learning implementations; review and customize them before publishing as your own GitHub repositories.
